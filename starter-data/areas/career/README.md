# Career

Promotion tracking, growth plans, leveling notes, strategic relationships. Anything that's about *you* (vs. about a project or a person you manage).

## Suggested structure

- `goals.md` — what you're working toward this quarter / year
- `growth-plan.md` — your manager's notes + your own evidence + work products
- `network.md` — sponsor / mentor / peer relationships you're investing in
- `wins.md` — running list of accomplishments worth surfacing in self-reviews

(These are suggestions. Add or rename freely.)

If you manage other people and need to level them, `/level-candidate` reads from your repo's leveling framework + heuristics. The framework files (`eng-leveling-framework.md`, `leveling-guidelines.md`) live here once you populate them.
